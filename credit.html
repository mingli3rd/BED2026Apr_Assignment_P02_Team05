Credits & Sources

Fonts, libraries, and external media used throughout this project.

Fonts

  • Google Fonts — Anton, IBM Plex Sans, and IBM Plex Mono, used under the SIL Open Font License. fonts.google.com

Backend & Database

  • Node.js & Express — server runtime and web framework used to build the RESTful API. expressjs.com
  • Microsoft SQL Server — relational database, accessed via the mssql Node.js driver. npmjs.com/package/mssql
  • dotenv — loads configuration and secrets from .env files. npmjs.com/package/dotenv

Validation & Security

  • Joi — schema validation for incoming request bodies. joi.dev
  • bcrypt — hashes user passwords before storage. npmjs.com/package/bcrypt
  • jsonwebtoken — issues JWT session tokens for login authentication. npmjs.com/package/jsonwebtoken
  • cookie-parser — reads the JWT auth cookie. npmjs.com/package/cookie-parser
  • cors — enables the main site to safely call the separate NEA service across origins. npmjs.com/package/cors

Image Upload & Charts

  • multer — parses multipart image uploads. npmjs.com/package/multer
  • sharp — auto-rotates, resizes, and compresses uploaded photos server-side. sharp.pixelplumbing.com
  • Chart.js — renders the sales and rating charts on the vendor Performance dashboard. chartjs.org

Images & Media

  • Stall & Hawker Centre Photos — Pictures from google images taken for hawker centres.
